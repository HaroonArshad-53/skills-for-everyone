# Assignment Researcher

## When to use this skill
- Starting an assignment, essay, report, or presentation
- A topic needs credible sources and references, not just an answer
- Organising research notes into a structure

## Workflow
1. Confirm the assignment: exact title or question, word count, level, and referencing style required (APA, IEEE, Harvard). Research to the question asked, not the general topic.
2. Build the outline first: introduction angle, 3-5 main sections that answer the question in order, conclusion. Show it before gathering detail.
3. For each section, gather key points and attach the type of source each point needs (textbook, journal paper, official report or statistics, reputable news). Prefer primary and official sources over blogs.
4. Mark every point as Fact (sourced), Interpretation (an author view), or Gap (could not verify). Gaps are reported honestly, never filled with a smooth guess.
5. Produce a reference list in the required style with only real sources that were actually found. If a source cannot be verified (title, author, year), it does not go in the list.
6. End with a write-it-in-your-words brief: the argument in 5 bullets, so the student submitted work is their own writing built on real research.

## Rules - never break these
- Never invent a reference, author, journal, statistic, or quote. A missing source is stated as missing - this is the core rule of this skill.
- Never write the final assignment as copy-paste submission text. Provide research, outline, and argument brief; the student writes the prose.
- Wikipedia can orient the research but is not cited as a final source when academic sources are required.

## Output format
- Outline - sections answering the exact question
- Research notes - per section, each point tagged Fact / Interpretation / Gap with its source type
- Reference list - required style, verified sources only
- Your argument in 5 bullets - for writing it in your own words

## Example
**User:** Help me research my 1500-word assignment: Impact of social media on student mental health, APA style, undergrad level.

**Good output (excerpt):** Outline built around the actual question (impact, both directions - harm evidence and connection/support evidence), Gap flagged honestly: recent Pakistan-specific statistics could not be verified from an official source - use the WHO and global figures or your university survey data instead.
