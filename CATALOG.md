# Catalog - Skills for Everyone

Every skill in this repo, grouped by bundle. Each skill is a folder under `skills/` containing one `SKILL.md`.

## Freelancer Bundle

| Skill | What it does |
|---|---|
| [client-brief-analyzer](skills/client-brief-analyzer/SKILL.md) | Turn a messy client message, job post, or voice-note transcript into a clear project brief with scope, deliverables, missing information, red flags, and questions to ask before accepting the work. |
| [proposal-writer](skills/proposal-writer/SKILL.md) | Write a specific, non-spammy freelance proposal for Upwork, Fiverr, Contra, or direct clients, based on the client actual job post and the freelancer real skills and past work. |
| [project-scope-planner](skills/project-scope-planner/SKILL.md) | Divide an accepted freelance project into clear milestones, tasks, deliverables, dependencies, and a realistic timeline, and produce a scope document the client can approve before work starts. |
| [pricing-calculator](skills/pricing-calculator/SKILL.md) | Calculate a fair freelance project price or hourly rate from hours, experience level, platform fees, rush deadlines, and revision rounds, and present a low, recommended, and high quote with the reasoning. |
| [professional-email](skills/professional-email/SKILL.md) | Rewrite rough notes, mixed-language drafts (including Roman Urdu, Hinglish, or broken English), or emotional first drafts into clear, professional emails and client messages with the right tone. |
| [portfolio-case-study](skills/portfolio-case-study/SKILL.md) | Turn rough notes about a finished project into a portfolio case study and a short LinkedIn or social post that proves skill with the problem, process, and result, without inventing metrics. |

## Student & First-Job Bundle

| Skill | What it does |
|---|---|
| [study-any-topic](skills/study-any-topic/SKILL.md) | Teach any topic in simple language with a real-life example, then test understanding with a short quiz and flashcards, adjusting depth for school, university, or interview level. |
| [fyp-project-manager](skills/fyp-project-manager/SKILL.md) | Plan and manage a final-year project, semester project, or thesis like a project manager: interview the student, write a plan file, divide the project into weekly tasks with deliverables, and run check-ins that compare progress against the plan. |
| [assignment-researcher](skills/assignment-researcher/SKILL.md) | Research a topic for an assignment or presentation using a structured, source-first method: build an outline, gather points from real, citable sources, separate facts from opinions, and produce a draft structure the student writes in their own words. |
| [interview-griller](skills/interview-griller/SKILL.md) | Prepare a user for a job interview, internship interview, or viva by asking tough questions one at a time, like a real interviewer, then scoring each answer and teaching the improvement. |
| [resume-builder](skills/resume-builder/SKILL.md) | Build an ATS-friendly resume or CV from messy notes, an old resume, or a LinkedIn profile, tailored to a specific job description when one is provided, without inventing experience. |
| [learn-in-30-days](skills/learn-in-30-days/SKILL.md) | Turn any skill or subject the user wants to learn into a realistic 30-day plan with daily tasks, weekly projects, free-resource types for each step, and weekly self-tests, sized to the hours per day the user actually has. |
